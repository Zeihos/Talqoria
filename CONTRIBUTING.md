# Как помочь развитию TALQORIA

Спасибо за интерес к TALQORIA! Репозиторий открыт для замечаний, сообщений об ошибках и предложений по улучшению.

## Перед началом

- Ознакомьтесь с [README](README.md) и [планом разработки](docs/ROADMAP.md).
- Для ошибки откройте [Issue](https://github.com/Zeihos/Talqoria/issues/new/choose) и укажите воспроизводимые шаги.
- Для предложения опишите проблему игрока и ожидаемый результат.
- Не публикуйте токены, IP-адреса частных серверов, файлы сохранений игроков или закрытую информацию.

## Работа с кодом

1. Создайте отдельную ветку от `main`.
2. Старайтесь делать изменения небольшими и целевыми.
3. Добавляйте тесты, если меняется логика сохранений, экономики или приватов.
4. Проверьте `mvn -f plugin/pom.xml clean package` и `node --test backend/test/*.test.js`.
5. Откройте Pull Request с пояснением, что изменилось, как это проверено и есть ли риск для данных.

## Правила

- Код Java располагается в `plugin/src/main/java/ru/talqoria/core/`.
- Изменения в сайте — `site/`, backend — `backend/`.
- Не загружайте `target/`, `node_modules/`, `server/world/`, логи, готовые JAR и файлы игровых аккаунтов.
- Не меняйте формат сохранений без миграции и теста восстановления.
- Не отключайте безопасные режимы ради прохождения проверки.
- Не заявляйте об успешном тестировании на Paper, если был проверен только Maven или автономные тесты.
- Текст обращений и документации предпочтительно писать на **русском**; имена файлов и программные идентификаторы сохраняйте понятными для инструментов разработки.

## Лицензирование

У проекта пока нет выбранной лицензии. Возможность просматривать код и отправлять предложения не означает автоматического разрешения на его использование или распространение в сторонних проектах.

Для начала обсуждения создайте [Issue](https://github.com/Zeihos/Talqoria/issues).
