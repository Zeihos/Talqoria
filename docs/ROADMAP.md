# План разработки TALQORIA

[← На главную](../README.md)

**Текущий этап:** TalqoriaCore **0.15.0 Developer Alpha**. Номера следующих версий и содержание этапов могут меняться по результатам тестов.

## Фундамент

- [x] Первые команды `/tq`, профиль и баланс (ручная проверка базовых команд на 0.11)
- [x] Исходники поселений, ролей и приватов
- [x] Ежедневные задания, путь новичка, экономика
- [x] Прототип сайта и Node.js API
- [x] Автоматическая сборка TalqoriaCore и тесты через GitHub Actions
- [x] Журнал блоков для антифарма, восстановление данных и диагностика медленных операций в коде 0.13

- [ ] Запустить **именно TalqoriaCore 0.15** на выбранной версии Paper

- [ ] Проверить сохранение кошельков, заданий и поселений после перезапуска
- [ ] Исследовать задержки главного потока с помощью встроенного spark
- [x] В 0.14 добавлены резервный снимок блоков и автономная проверка повреждённого журнала
- [x] В 0.15 добавлена защита истории выплат кошельков и JUnit-тесты восстановления
- [ ] Проверить восстановление после частичной записи и повреждения журналов на настоящем Paper
