# Установка и запуск TALQORIA

> Документ для разработчиков и тестировщиков. TalqoriaCore 0.19.0 — Developer Alpha, а не готовый публичный сервер.

[← На главную](../README.md) · [План работ](ROADMAP.md)

## 1. Требования

| Компонент | Требование |
|:--|:--|
| Java | JDK 21+ для компиляции; для проверявшегося Paper 26.3 использовалась Java 25 |
| Maven | 3.9+ (Windows-скрипт может загрузить Maven локально) |
| Node.js | 20+ для сайта и API |
| Paper | Совместимая с вашей версией Minecraft сборка |

`plugin/pom.xml` в текущей версии привязан к `paper-api:1.21.11-R0.1-SNAPSHOT`. Игровая совместимость TalqoriaCore 0.18 с Paper 26.3 **не подтверждена**. Проверка успешной компиляции не заменяет запуск и тестирование в игре.

## 2. Получение исходников

```bash
git clone https://github.com/Zeihos/Talqoria.git
cd Talqoria
```

Из репозитория намеренно исключены готовые миры, приватные файлы, токены и серверный JAR Paper.

## 3. Сборка плагина

**Windows:** запустите `BUILD_PLUGIN_WINDOWS.bat` из корня проекта. Если Maven не установлен, скрипт использует `tools/install-maven.ps1` для локальной установки без изменений системного PATH.

**Терминал:**

```bash
mvn -f plugin/pom.xml clean package
```

После сборки создаётся `plugin/target/talqoria-core-0.19.0.jar`. Для установки его необходимо скопировать как `server/plugins/TalqoriaCore.jar`.

Альтернативный вариант — открыть успешный прогон [GitHub Actions](https://github.com/Zeihos/Talqoria/actions/workflows/verify.yml) и скачать `TalqoriaCore-dev` из **Artifacts**. Это тестовая сборка.

## 4. Запуск Paper

1. Скачайте совместимый Paper с [официального сайта](https://papermc.io/downloads/paper) и поместите его в `server/paper.jar`.
2. Изучите `server/server.properties.example` — это **пример отдельных параметров**, а не полный конфиг. Используйте стандартный `server.properties`, который создаёт Paper, и настройте его вручную.
3. Для закрытого теста включите `online-mode=true`, `white-list=true`, `enable-rcon=false`.
4. Запустите `server/start-windows.bat` либо `server/start-linux.sh`.
5. Если Paper просит принять EULA, прочитайте условия и **самостоятельно** установите `eula=true`, только если согласны.
6. Повторно запустите сервер. Проверьте наличие `Enabling TalqoriaCore v0.19.0` в логах и команды `/tq help`, `/tq balance`.

**Предварительная диагностика:** из корня репозитория запустите `node tools/preflight.js .` или `PREFLIGHT_WINDOWS.bat` на Windows (`./PREFLIGHT_LINUX.sh` на Linux). Можно передать путь к каталогу проекта или `server/`. Проверка не изменяет файлы и помогает обнаружить отсутствующие JAR, открытый RCON, выключенную авторизацию и риски сохранений. Наличие результата READY не равно успешному тесту Paper.

## 5. Сайт и API

**Windows:** `START_SITE_WINDOWS.bat`. **Linux:** запустите `backend/start-linux.sh`.

При стандартных настройках сайт работает на `http://127.0.0.1:8080`. Он является прототипом; разделы кабинета и административного интерфейса не являются полнофункциональной панелью управления.

Для мониторинга Paper используется токен `TALQORIA_BRIDGE_TOKEN`, заданный в окружении API и Minecraft-сервера. Не публикуйте его в репозитории и не передавайте по незащищённому HTTP на внешние адреса.

```bash
node --test backend/test/*.test.js
node tools/repo-check.js
```

## 6. Обновление действующего сервера

1. Выполните `stop` в консоли Paper и дождитесь завершения процесса.
2. Сделайте отдельную резервную копию `server/world/` и `server/plugins/TalqoriaCore/`. При необходимости воспользуйтесь `BACKUP_OFFLINE_WINDOWS.bat` **только при остановленном сервере**.
3. Замените только `server/plugins/TalqoriaCore.jar` на новую собранную версию.
4. **Не удаляйте и не перезаписывайте** `players.yml`, `territories.xml`, `quests.xml`, `placed-blocks.xml`, `placed-blocks.xml.bak` и `placed-blocks.journal`.
5. Запустите Paper и выполните тест команд, приватов и сохранений. При ошибках записи прекратите тестирование и проверьте резервную копию.

**Не копируйте весь каталог с исходниками поверх действующего сервера.** Он не содержит игрового мира.

## 7. Типичные проблемы

| Симптом | Что проверить |
|:--|:--|
| `Maven 3.9+ is required` | Запустите новый `BUILD_PLUGIN_WINDOWS.bat` или установите Maven 3.9+ |
| `Failed to verify username` | Повторная авторизация в официальном лаунчере; для публичного сервера `online-mode=true` |
| `Timed out waiting for world statistics` | Отчёт spark, нагрузка на основной поток, другие плагины |
| `TalqoriaCore.jar` не загрузился | Соответствие Java, Paper API и версии JAR; полный `latest.log` |
| Данные заблокированы после ошибки | Сначала резервная копия и сверка файлов; не удаляйте журнал или `.bak` вслепую |
| Кошельки заблокированы после запуска | Сравните `players.yml` и `players.yml.bak`: не исчезли ли отметки уже выплаченных наград или дата ежедневного получения |
| Задания заблокированы после запуска | Сравните `quests.xml` и `quests.xml.bak`: не исчезли ли игроки, отметки о наградах или прогресс за один день; сохраняйте обе копии |
| Приваты заблокированы после запуска | Сохраните оба файла `territories.xml` и `territories.xml.bak`; проверьте контрольную сумму, ревизии и сведения о чанках через офлайн-инспектор |

Проблемы присылайте в [Issues](https://github.com/Zeihos/Talqoria/issues), предварительно скрыв личные данные и токены.
