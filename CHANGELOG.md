# История изменений TALQORIA

[← Главная](README.md)

Здесь зафиксированы **подтверждённые изменения репозитория**, а не обещания игрового релиза.

## 22 ноября 2026 — TalqoriaCore 0.16.0 Developer Alpha

- Усилена сверка `quests.xml` и `quests.xml.bak`: исчезновение игрока, откат дня, уменьшение прогресса за один день и потеря отметки о выданной награде переводят задания в режим восстановления без изменений.
- Сброс ежедневных целей при наступлении **следующего** дня UTC остаётся разрешённым.
- Резервная копия заданий обновляется через временный файл с подтверждением записи на диск, чтобы прерванное копирование не портило предыдущую `.bak`.
- Добавлены JUnit-тесты прогресса, наград, восстановления, повреждённой копии и перехода на новый день.
- Согласованы версии исходников, сайта, API и сборочных скриптов; игровое тестирование Paper 26.3 по-прежнему требуется.

## 18 ноября 2026 — TalqoriaCore 0.15.0 Developer Alpha

- Кошельки проверяют историю полученных наград и даты ежедневных выплат при загрузке вместе с резервным `players.yml.bak`.
- Если в основном файле отсутствуют оплаченные награды или дата выплаты откатилась назад, включается режим восстановления без дополнительных начислений.
- Резервная копия кошелька заменяется через временный файл, уменьшая риск повреждения предыдущей копии при прерывании записи.
- Добавлены тесты JUnit на реальные YAML-сохранения: переводы, ежедневные награды, повреждённые файлы и повторные выплаты.
- Исходники и автоматическая сборка обновлены до v0.15; это всё ещё Developer Alpha, игровой тест на Paper необходим.

## 18 ноября 2026 — TalqoriaCore 0.14.0 Developer Alpha

- При сохранении состояния блоков записывается резервный XML-снимок `placed-blocks.xml.bak`.
- Пропавший основной снимок при наличии резервного теперь вызывает защитную блокировку, а не создание пустого хранилища.
- Офлайн-инспектор проверяет журнал блоков, включая целостность и возможность восстановления, в режиме только чтения.
- Предзапускная диагностика отмечает повреждение/обрыв журнала и отсутствие основного снимка.
- Исправлен учёт происхождения блоков при разрушении в творческом режиме без начисления заданий.
- Добавлены автономные проверки Java и Node.js. Реальный игровой тест 0.14 на Paper ещё не проводился.

- [PR #2](https://github.com/Zeihos/Talqoria/pull/2): синхронизирован код TalqoriaCore 0.13.0, добавлены защищённый журнал блоков и диагностика медленных действий.
- [PR #1](https://github.com/Zeihos/Talqoria/pull/1): пакетное обновление журнала блоков при взрывах и автоматические Java/Node.js проверки.
- Последующая ревизия: исправление команд диагностики, согласование версий и проверка структуры/ссылок в CI.

## TalqoriaCore 0.13.0 — Developer Alpha

- Журнал происхождения блоков с проверкой целостности, восстановлением и безопасной блокировкой при ошибках записи.
- Сохранение прогресса заданий при выходе игрока и диагностика медленных команд.
- GitHub Actions проверяет сборку и автономные тесты.

**Не подтверждено:** полноценная игровая совместимость версии 0.13 с Paper 26.3, нагрузочные тесты, безопасность торговли.

## Обновление

Перед заменой JAR остановите Paper и сделайте резервные копии мира и `plugins/TalqoriaCore/`. Не удаляйте `placed-blocks.xml` и `placed-blocks.journal`: оба файла могут быть нужны для восстановления.

Подробнее: [установка](docs/INSTALL.md), [план разработки](docs/ROADMAP.md).
