# Безопасность TALQORIA

[← Главная](README.md)

TALQORIA находится на стадии **Developer Alpha**. Мы заинтересованы в ответственных сообщениях об уязвимостях, но не обещаем конкретного срока исправления.

## Как сообщить о проблеме

1. **Не публикуйте** способы эксплуатации, токены, данные игроков или полный архив сервера в открытом Issue.
2. В разделе **Security** репозитория проверьте возможность приватного сообщения (*Report a vulnerability*). Наличие функции зависит от настроек GitHub.
3. Если этот способ недоступен, свяжитесь с владельцем репозитория **Zeihos** через доступный вам личный канал. Не отправляйте секреты публично.

Обычные ошибки интерфейса и сборки можно описывать в [Issues](https://github.com/Zeihos/Talqoria/issues/new/choose).

## Игровые данные

Никогда не добавляйте в Git серверные миры, файлы игроков, токены API, журналы действий администрации, `server.properties` и приватные настройки. Исторические коммиты могут сохранять ранее загруженные данные даже после удаления из `main`. Ветка `backup/pre-cleanup-20261117` **также публична**, пока репозиторий публичный.

Для тестового сервера рекомендуются `online-mode=true`, whitelist, выключенный RCON и резервные копии после остановки. При изменении режима авторизации UUID игроков могут измениться — требуется ручная сверка аккаунтов.

Сборки GitHub Actions **не являются подтверждёнными игровыми релизами**. Рынок в альфа-версии отключён по умолчанию.
